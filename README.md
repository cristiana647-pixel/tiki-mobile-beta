# TIKI móvil — beta

App web de edición de video para iPhone: importar varios clips, quitar silencios, generar subtítulos locales y exportar.

Abrir: https://cristiana647-pixel.github.io/tiki-mobile-beta/

La app procesa los videos en el teléfono. Esta distribución contiene solo archivos estáticos compilados y el modelo de voz con licencia MIT; no contiene grabaciones de usuarios.
